## 3. 파트별 예제 · 미션 · 과제

### 📘 01. 배열 생성

- **예제 1** 시험 점수 데이터 만들기 — 학생 30명 점수(0~100)를 랜덤 생성하고 평균/최고/최저/표준편차 구하기
- **예제 2** 출석부 초기화 — 5명 × 7일 출석표를 0으로 초기화 (0=결석, 1=출석)
- **예제 3** 구구단 표 — `np.arange(1,10)` 두 개를 곱해 9×9 표 만들기 (브로드캐스팅 맛보기)
- **미션 A** 중복 없는 로또 — `np.random.choice(범위, 개수, replace=False)` 로 중복 없는 로또 6개 뽑기
- **미션 B** 가위바위보 100판 — 0/1/2로 100판 랜덤 생성 후 손별 횟수 세기 (`np.unique(..., return_counts=True)`)
- **📝 과제** 월별 매출 데이터 종합 분석 (아래 4장 참고)

### 📗 02. 배열 연산 및 집계함수

- **예제 1** 섭씨→화씨 벡터화 변환 — 반복문 없이 배열 한 번에 (`화씨 = 섭씨 × 9/5 + 32`)
- **예제 2** 장바구니 10% 할인 — 가격 배열에 브로드캐스팅으로 할인 적용
- **예제 3** 학생×과목 점수표 집계 — 과목 평균(axis=0), 학생 평균(axis=1)
- **미션 A** 점수 표준화(z-score) — `z = (값 − 평균) ÷ 표준편차`
- **미션 B** 이미지 밝기 올리기 — 2차원 흑백 이미지 모든 픽셀에 +50 (컬러 이미지 예고편)
- **📝 과제** 성적 데이터 종합 분석 (아래 참고)

### 📙 03. 배열 선택 및 복사

- **예제 1** 성적표에서 골라 뽑기 — 인덱싱/슬라이싱으로 원하는 부분 추출
- **예제 2** 조건 필터 — boolean 인덱싱으로 60점 이상만
- **예제 3** 합격/불합격 라벨 — `np.where` 로 60점 기준 라벨링
- **미션** 슬라이싱 도전 — ① 거꾸로 만들기 ② 짝수 인덱스만 ③ 2차원 가운데만 잘라내기(이미지 자르기 맛보기)
- **📝 과제** 학생 성적 데이터 종합 선택 (아래 참고)

## 4. 📝 제출 과제 안내 (3개)

> 각 과제는 해당 노트북 마지막 셀에 있습니다. 완성한 노트북(`.ipynb`)을 제출하세요. (완성본에 정답은 포함되지 않습니다.)

### 과제 1 — 월별 매출 데이터 종합 분석 (01 파트)

1. 1~12월 매출을 100~500(만원) 랜덤 정수로 생성 (`seed(42)` 고정)
2. 배열의 `dtype`, `shape`, `size` 출력
3. 연 총매출, 월평균 매출 구하기
4. 매출이 가장 높은 '달'이 몇 월인지 (`argmax()` + 1)
5. (도전) 상반기(1~6월)·하반기(7~12월) 평균 비교

### 과제 2 — 성적 데이터 종합 분석 (02 파트)

1. 학생 6명 × 과목 4개(국·영·수·과) 점수를 50~100 랜덤 정수로 생성 (`seed(42)`)
2. 전 과목 +5점 가산(브로드캐스팅), 100점 넘지 않게 (`np.minimum(..., 100)`)
3. `axis` 로 과목별 평균 · 학생별 총점
4. `argmax` 로 총점 1등 학생 찾기
5. (도전) `std` 로 점수 편차가 가장 큰 과목 찾기

### 과제 3 — 학생 성적 데이터 종합 선택 (03 파트)

1. 학생 6명 × 과목 4개 점수를 20~100 랜덤 정수로 생성 (`seed(0)`)
2. 인덱싱으로 3번 학생(인덱스 3) 점수 조회
3. 슬라이싱으로 앞 3명 점수만 추출
4. 조건 필터로 평균 60 미만 학생 찾기 (`scores.mean(axis=1)`)
5. `np.where` 로 각 점수를 합격(60↑)/불합격 표로
6. 원본을 지키려면 왜 `copy()` 가 필요한지 주석으로 설명
